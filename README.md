# PhiloNote

初学者向けの哲学学習アプリです。難しい思想を「短く理解 → 比較 → 自分のメモ」に整理できます。

## Tech Stack
- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Vitest + React Testing Library

## セットアップ
```bash
npm install
npm run dev
```

## 主要コマンド
```bash
npm run dev
npm run lint
npm run test
npm run build
```

## MVP機能
- ホーム、哲学者一覧/詳細、用語一覧/詳細
- 哲学者2人比較
- 検索（部分一致・大文字小文字非区別）
- お気に入り・学習メモ（localStorage）
- ダークモード切替
